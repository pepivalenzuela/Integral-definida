Integral definida · Bloque 5

Área bajo una curva

Llevamos la integral definida al cálculo de áreas: el área entre una función, el eje OX y, si las hay, dos rectas verticales.

1 Los pasos antes de calcular

1.ºRepresentar (aunque sea a grandes rasgos) la función f.
2.ºDelimitar el recinto: los puntos de corte con el eje OX, f(x) = 0, y las rectas verticales si las hay.
3.ºEstudiar el signo de f en cada trozo.
4.ºUsar la simetría del recinto, si la hay.

2 Los tres casos

1.º caso · f ≥ 0 en [a, b]\(\displaystyle\text{Área}\)\(\displaystyle {}= \int_a^b f(x)\,dx\)
2.º caso · f ≤ 0 en [a, b]\(\displaystyle\text{Área}\)\(\displaystyle {}= \left|\int_a^b f(x)\,dx\right|\)
3.º caso · f cambia de signoSe calculan los cortes x₁, x₂, … con el eje, se divide el recinto y se suman los valores absolutos: \(\displaystyle\text{Área}\)\(\displaystyle {}= \left|\int_a^{x_1} f\right| + \left|\int_{x_1}^{x_2} f\right| + \dots\)
⚠️En el 3.er caso, \(\text{Área} \neq \left|\int_a^b f(x)\,dx\right|\): las partes de arriba y de abajo se compensarían.

3 Ejemplos resueltos

📝 Ejemplo 1 · Comprobar con la geometría

Interpreta \(\int_{-1}^{6} (2x+6)\,dx\) y calcula su valor.

Es el área bajo la recta y = 2x + 6 entre x = −1 y x = 6 (la recta es positiva ahí). Por geometría: 7·4 + 7·14/2 = 77 u².

Con Barrow: \(\Big[x^2+6x\Big]_{-1}^{6}\)\({}= (36+36)-(1-6)\)\({}= 77\ u^2\). ✔

📝 Ejemplo 2 · Una función que cambia de signo

Calcula el área limitada por f(x) = x³ − 4x y el eje de abscisas.

Cortes: x(x² − 4) = 0 ⇒ x = −2, 0, 2. f > 0 en (−2, 0) y f < 0 en (0, 2). Como f es impar, el recinto es simétrico:

\(\displaystyle\text{Área}\)\(\displaystyle {}= 2\int_{-2}^{0} (x^3-4x)\,dx\)\(\displaystyle {}= 2\left[\frac{x^4}{4}-2x^2\right]_{-2}^{0}\)\(\displaystyle {}= 2\big(0-(4-8)\big)\)\(\displaystyle {}= 8\ u^2\)

📝 Ejemplo 3 · Con rectas verticales

Calcula el área encerrada por y = x³ − x² − 2x, el eje OX y las rectas x = 0 y x = 2.

Cortes con OX: x(x² − x − 2) = 0 ⇒ x = −1, 0, 2. Entre 0 y 2 la función es negativa (prueba x = 1: f(1) = −2).

\(\displaystyle\text{Área}\)\(\displaystyle {}= \left|\int_0^2 (x^3-x^2-2x)\,dx\right|\)\(\displaystyle {}= \left|\left[\frac{x^4}{4}-\frac{x^3}{3}-x^2\right]_0^2\right|\)\(\displaystyle {}= \left|4-\frac83-4\right|\)\(\displaystyle {}= \frac83\ u^2\)

📝 Ejemplo 4 · Con un logaritmo

Área entre \(y=\dfrac{6x}{x^2+1}\) y el eje OX para x ∈ [2, 5].

La función solo se anula en x = 0, así que en [2, 5] es positiva.

\(\displaystyle\int_2^5 \frac{6x}{x^2+1}\,dx\)\(\displaystyle {}= \Big[3\ln(x^2+1)\Big]_2^5\)\(\displaystyle {}= 3\ln 26 - 3\ln 5\)\(\displaystyle {}= 3\ln\frac{26}{5} \approx 4.95\ u^2\)

📝 Ejemplo 5 · Hallar un parámetro

Calcula a > 0 sabiendo que el área encerrada por y = ax² + 2, el eje X y las rectas x = −1 y x = 2 es 21.

ax² + 2 > 0 siempre (a > 0): la función no corta al eje.

\(\displaystyle\int_{-1}^{2} (ax^2+2)\,dx\)\(\displaystyle {}= \left[\frac{ax^3}{3}+2x\right]_{-1}^{2}\)\(\displaystyle {}= \frac{8a}{3}+4+\frac a3+2\)\(\displaystyle {}= 3a+6\)\(\displaystyle {}= 21\)\(\displaystyle {}\Rightarrow \boxed{a = 5}\)
