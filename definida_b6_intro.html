Área entre dos funciones

El área entre dos curvas es el área bajo la función diferencia. El secreto está en saber cuál va por encima y dónde se cortan.

1 Una función por encima de la otra

Si f(x) ≥ g(x) en [a, b], el área entre las dos y las rectas x = a, x = b es el área bajo la función diferencia h(x) = f(x) − g(x) ≥ 0:

Área entre dos funciones

\[\text{Área} = \int_a^b \big(f(x)-g(x)\big)\,dx\]

(f la de arriba, g la de abajo)

💡No importa que las funciones estén por encima o por debajo del eje OX: solo importa cuál está arriba. Si no sabes cuál es, calcula \(\left|\int_a^b (f-g)\,dx\right|\).

2 Las funciones se cortan

1.ºHallar los puntos de corte resolviendo f(x) = g(x).
2.ºEn cada trozo entre dos cortes (y las verticales, si las hay), ver qué función va arriba (basta probar un punto).
3.ºSumar las áreas de cada trozo: \(\displaystyle A\)\(\displaystyle {}= \int_{x_1}^{x_2} (f-g)\,dx + \int_{x_2}^{x_3} (g-f)\,dx + \dots\)
📝 Ejemplo 1 · Parábola y recta

Área del recinto limitado por y = x² e y = x + 2.

Cortes: x² = x + 2 ⇒ x² − x − 2 = 0 ⇒ x = −1, x = 2. En x = 0: recta 2, parábola 0 ⇒ la recta va arriba.

\(\displaystyle A\)\(\displaystyle {}= \int_{-1}^{2} (x+2-x^2)\,dx\)\(\displaystyle {}= \left[\frac{x^2}{2}+2x-\frac{x^3}{3}\right]_{-1}^{2}\)\(\displaystyle {}= \frac{10}{3}-\left(-\frac76\right)\)\(\displaystyle {}= \frac92\ u^2\)

3 Ejemplos de PEvAU y de clase

📝 Ejemplo 2 · PEvAU Andalucía, Matemáticas II, 2007 (Reserva 1)

f(x) = eˣ⁻¹ y g(x) = e¹⁻ˣ. a) Esboza las gráficas y halla su punto de corte. b) Calcula el área del recinto limitado por el eje OY y las gráficas de f y g.

a) eˣ⁻¹ = e¹⁻ˣ ⇒ x − 1 = 1 − x ⇒ x = 1: punto (1, 1). f es creciente y pasa por (0, 1/e); g es decreciente y pasa por (0, e).

b) Entre x = 0 y x = 1 va arriba g: \(\displaystyle A\)\(\displaystyle {}= \int_0^1 (e^{1-x}-e^{x-1})\,dx\)\(\displaystyle {}= \Big[-e^{1-x}-e^{x-1}\Big]_0^1\)\(\displaystyle {}= -2+e+\frac1e \approx 1.086\ u^2\)

📝 Ejemplo 3 · Tres funciones y simetría

Región limitada por \(f(x)=\frac54x^2\), \(g(x)=\frac12(5x+20)\) y \(h(x)=\frac12(-5x+20)\).

Cortes: P(−2, 5) entre f y g; Q(2, 5) entre f y h; R(0, 10) entre g y h. La región es simétrica respecto al eje OY:

\(\displaystyle A\)\(\displaystyle {}= 2\int_0^2 \left(\frac{-5x+20}{2}-\frac54x^2\right)dx\)\(\displaystyle {}= 2\left[10x-\frac{5x^2}{4}-\frac{5x^3}{12}\right]_0^2\)\(\displaystyle {}= 2\left(20-5-\frac{10}{3}\right)\)\(\displaystyle {}= \frac{70}{3}\ u^2\)

📝 Ejemplo 4 · Hallar un parámetro

Calcula β > 0 para que el área limitada por f(x) = x² y g(x) = −x² + 2β² sea 72.

Cortes: x² = −x² + 2β² ⇒ x² = β² ⇒ x = ±β. Entre ellos va arriba g (en x = 0, g = 2β² > 0).

\(\displaystyle A\)\(\displaystyle {}= \int_{-\beta}^{\beta} (2\beta^2-2x^2)\,dx\)\(\displaystyle {}= \left[2\beta^2x-\frac{2x^3}{3}\right]_{-\beta}^{\beta}\)\(\displaystyle {}= \frac{8\beta^3}{3}\)\(\displaystyle {}= 72\)\(\displaystyle {}\Rightarrow \beta^3\)\(\displaystyle {}= 27\)\(\displaystyle {}\Rightarrow \boxed{\beta = 3}\)

📝 Ejemplo 5 · Con un valor absoluto

Área del recinto limitado por f(x) = |ln x| y la recta y = 1.

|ln x| = 1 ⇒ ln x = −1 o ln x = 1 ⇒ x = 1/e, x = e. Entre ellos va arriba la recta. Hay que partir en x = 1, donde cambia |ln x|:

\(\displaystyle A\)\(\displaystyle {}= \int_{1/e}^{1} (1+\ln x)\,dx + \int_1^e (1-\ln x)\,dx\)\(\displaystyle {}= \Big[x\ln x\Big]_{1/e}^{1} + \Big[2x-x\ln x\Big]_1^e\)\(\displaystyle {}= \frac1e + (e-2) \approx 1.086\ u^2\)
